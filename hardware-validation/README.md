# Preserved engineering review evidence

This folder preserves the dated independent review, its calculation and wiring inputs, and files needed to reproduce the earlier Blender reference. Nothing here records a physical test.

`ASTRA_3D_WIRING_HANDOFF_FINAL.md`, `corrected-wiring-table.csv`, `assembly-reference.json`, `wire-routes.json`, `corrected-schematic.png`, and the calculation files belong to an earlier conditional design revision. The later `FINAL_EV_EMS_ENGINEERING_PACKAGE/` is the current engineering handoff and must be used for website claims. The older 3D metadata is intentionally not loaded by the website.

`provided-references/` contains selected superseded audit inputs cited by the dated review. Duplicate copies, old browser screenshots, abandoned viewer files and backup material have been removed. Retained model files and generator scripts are described in `../blender-workflow/README.md`.
